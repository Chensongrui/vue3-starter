## 项目架构分析（vue3-starter）

对工程做了一次完整架构梳理（只读，未改动代码）。

**技术栈**：Vue 3.5 + Vite 6 + TypeScript 5.7 + Vue Router 4 + Pinia 2 + Element Plus 2.9 + Axios 1.7 + Sass。

**分层结构**（自上而下）：
1. 启动入口：index.html → src/main.ts（全局注册 Element Plus + 全部图标 + 中文语言包、注册 router、setupStore）
2. 路由布局：src/router/index.ts（导出 `menuRoutes` 供菜单复用）、src/layout/index.vue（侧边栏+顶栏+面包屑+过渡动画）、layout/components/Sidebar.vue
3. 视图层：views/home、about、demo/{table,form,store}、error/404
4. 状态层：Pinia，全部使用 setup 组合式写法，modules/{app,user,counter}，index.ts 统一 `export *`
5. 网络层：api/request.ts（axios 封装 + 请求/响应拦截器，约定 `{code,data,message}`，code 0/200 为成功且自动剥壳返回 data）、api/user.ts
6. 后端：开发期通过 vite proxy `/api` → `VITE_PROXY_TARGET`（默认 http://localhost:8080），并 rewrite 去掉 /api 前缀

**关键设计点**：

- 构建按 manualChunks 拆包：vue 系、element-plus 各成独立 chunk。实测 dist 中 element-plus 约 1.06MB、vue 约 109KB、index.css 约 355KB。
- 路由守卫仅做 document.title 设置，未做登录鉴权。

**发现的待完善点**：
1. 无登录页、无鉴权守卫，user store 的 login 是 mock，token 只写本地存储。
2. Element Plus 全量引入 + 全量图标注册，打包体积偏大，未做按需引入。
3. `meta.icon` 是字符串 + `<component :is>` 动态渲染，依赖图标已全局注册；TS 层面对 meta 字段无类型扩展（未声明 `RouteMeta`）。

## 已解决：agent-browser 端到端验证跑通了

**根因（重要）**：之前 `agent-browser open` 挂死不是环境问题，是**管道假死**。
agent-browser 会启动常驻 daemon，daemon 继承了 stdout；一旦写成
`agent-browser open ... | tail`，管道写端被 daemon 一直持有，`tail` 永远等不到 EOF，
于是整条命令无输出、永不返回。前两次"卡死 4 分钟"都是这个原因。

**正确用法**：不要用管道，把输出重定向到**文件**再读：

```bash
timeout 90 "$AB" open <url> > /tmp/ab.log 2>&1 < /dev/null
```

`< /dev/null` 断开 stdin，`timeout 90` 兜底。读日志文件不会有 EOF 问题。

**安装路径**：
- 包不装全局（违反运行时隔离规则），装到 `C:\Users\Admin\.workbuddy\binaries\node\workspace`
  （该目录原本不存在，需先 mkdir），用 `node_modules/.bin/agent-browser` 调用。
- Chromium 用 `agent-browser install` 装，约 43s / 196MB，
  位置 `C:\Users\Admin\.agent-browser\browsers\chrome-153.0.8010.36`。
- 插件自带 `setup.sh` 在 Windows 上会失败（把 `/c/...` 路径传给 `powershell -File`），
  `install-windows.ps1` 也会失败（`$LASTEXITCODE` 未定义）。直接手动跑上面两步即可。

**使用要点（踩过的坑）**：
1. **ref 是会话级的**：跨命令/跨脚本后 ref 失效报 `Unknown ref`。必须先 `snapshot -i`
   拿到当次会话的 ref，再 `click @eN`。整个流程要放在**同一个 bash 进程**里连续执行。
2. `find text click "xxx"` 会误命中（页面上多个 role=menuitem），优先用 ref 或精确 CSS 选择器。
3. daemon 偶发中途挂掉导致后续命令挂起；重跑前先 `agent-browser close --all`。
4. 本机有 `http_proxy=127.0.0.1:61089`，访问 localhost 必须 `NO_PROXY=localhost,127.0.0.1`，
   否则 curl 拿到 502。
5. PowerShell 工具在本环境不回传 stdout，需要 `Out-File` 到临时文件再用 Read 读。
6. 截图路径要用 Windows 形式（`C:/...`），`/c/...` 会报 `os error 3`。
7. 临时文件批量 `rm` 会被 SIGTERM 杀掉，用 `find <dir> -maxdepth 1 -name "xxx" -delete`。

**登录/守卫端到端验证结果（全部通过）**：
| 场景 | 期望 | 实际 |
|---|---|---|
| 未登录访问 `/` | 跳 `/login?redirect=/home` | ✅ 一致 |
| 点击登录 | 进入 `/home`，顶栏显示"管理员" | ✅ 一致 |
| 登录后刷新 | 停留 `/home` 不弹回 | ✅ 一致 |
| 退出登录 → 确定 | 回到 `/login` | ✅ 一致（截图与登录页哈希相同） |
| 退出后访问 `/demo/table` | 跳 `/login?redirect=/demo/table` | ✅ 一致 |
